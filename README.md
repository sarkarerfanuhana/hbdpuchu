## 🚀 How to Host on GitHub Pages (Step-by-Step)

### Option 1: Via GitHub Website (Drag & Drop)
1. Go to [github.com](https://github.com) and click **"New repository"**.
2. Name it (for example: `subarna-21` or `for-sonu`).
3. Set visibility to **Public**, and click **"Create repository"**.
4. On the next screen, click **"uploading an existing file"**.
5. Drag and drop all the contents inside your Desktop folder:
   `/Users/sarkarerfanuhana/Desktop/subarna-birthday-website`
   *(Make sure `index.html`, `css/`, `js/`, and `assets/` are at the root level)*.
6. Click **"Commit changes"**.
7. Go to **Settings** > **Pages** (on the left sidebar).
8. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
9. In ~1 minute, GitHub will give you the live link (e.g. `https://<your-username>.github.io/subarna-21/`) to send to Subarna!

### Option 2: Via Terminal (Git Push)
Since this repository is already initialized with an initial commit, just run:

```bash
cd /Users/sarkarerfanuhana/her
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
git branch -M main
git push -u origin main
```

Then enable GitHub Pages under **Repository Settings > Pages > Branch: main > Save**.
